    21→Stage Summary:
    22→- ERP integration strategy: LIVE session-based connector (attempts real sync with user's credentials, honest failure reporting) + DEMO simulator connector (clearly labeled, evolves data over time to demonstrate the full sync pipeline without real credentials). Demo mode ON by default; auto-disables when a real live sync succeeds.
    23→- Core calc: attendance% = present/total×100; classesToReachTarget = ceil((target·total−100·present)/(100−target)); classesCanSkip = floor(100·present/target − total).
    24→- Architecture: connectors → sync engine (change detection → DB update → recalc → notifications) → REST API → single-page UI (4 tabs). Background scheduler via Next.js instrumentation.ts (periodic sync + failure backoff), plus manual [Sync Now].
